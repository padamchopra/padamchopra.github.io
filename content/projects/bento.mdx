Compose navigation is a pile of string keys until someone makes it a type. I wanted the type.

<Shot src="/projects/bento/stack.svg" alt="Typed screens stacked, a modal that returns a Uri" />

Bento is a navigation framework on Navigation3 — Mavericks, Koin, KSP. Screens, results, modals, shared elements, generated at compile time. A library, not an app.

Navigation3 was still alpha when I wired this. Results and modals have to be first-class or people fall back to bundles, and then the types were theatre. That’s the whole fight.
