GitHub has no API for the nice attachment URLs in a PR description. Those are minted by the website’s uploader. Drag it in by hand, or pretend to be a person.

<Shot src="/projects/github-pr-media/terminal.svg" alt="github login, then attach a walkthrough to a PR" />

This pretends. A CLI named `github` drives a real Chromium with Playwright, on a profile you sign into once. It opens the PR, clicks Edit, attaches the files, waits, saves. Nothing is committed.

It appends; it does not replace the body. The agent skill exists so I can say “put this video on the PR” and walk away — which only works because the browser session is already logged in.
